# AyuGram-Desktop-Native-Linux-Installation-Guide-Flatpak-Sandbox-Bypass-
This guide provides a clean, native installation path for running AyuGram Desktop on modern Linux distributions (such as Linux Mint or Ubuntu) when standard Flatpak installations fail due to custom desktop themes, XX11 display socket restrictions, or qt.qpa.xcb: could not connect to display security cookie blocks.
